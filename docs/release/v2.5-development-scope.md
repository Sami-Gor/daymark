# Daymark V2.5 development scope

## Offline multilingual narration (this workstream)

- Three production voices: English `bm_fable`, French `ff_siwis`, Spanish `em_alex`.
- Selected UI locale determines narration; no independent voice selector and no silent voice substitution.
- All assets bundled; no runtime downloads.
- Physical/offline acceptance, human listening and Android performance benchmark remain release gates.

## Separate V2.5 workstreams (not changed here)

- Ask Daymark ASR / 200-utterance benchmark.
- ONNX Runtime 1.31.0 evaluation.
- Android weather widget.

This scope does not authorise a production AAB, Play upload, version change or main-branch merge.
