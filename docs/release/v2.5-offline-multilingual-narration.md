# Daymark 2.5 — Offline Multilingual Narration (Hear today)

Status: **candidate implementation; physical-device acceptance pending**

Baseline: `8a28892fec6903b765882a8ee5bf470ce6f0200b` (tree `4dac94dd736b782608876374ed77cd1be78b7319`), v2.1.0.

## Architecture

- Android-only, fully offline native Kokoro TTS. No cloud TTS, Android system-TTS or browser fallback.
- `CurrentWeather` selects the narration locale from the selected Daymark UI locale and joins the existing `useDaymarkSpeech`/`speech-router` path.
- Voice policy: `en-GB`/`bm_fable`, `fr-FR`/`ff_siwis`, `es-ES`/`em_alex`.
- Rust JNI (`libkokoro_jni.so`) links piper-plus-g2p 0.5.3 for French/Spanish and the existing Misaki English path for English.
- The native library is built from pinned `pguso/kokoro` commit `b42bd5cf915163607cb51984cabf273dcf09755e` with the prephonemized synthesis patch.
- English uses the native streaming API. French/Spanish native streaming is not available in the pinned Kokoro API, so the Java engine uses a production **segmented synthesis/playback** path: synthesize the first sentence, start AudioTrack, then synthesize/play remaining segments. It does not wait for the full report.

- Physical Xiaomi acceptance was not performed because the device was disconnected at install/test time.
- Human listening review for English/French/Spanish is pending.

## Testing procedure

1. Build the debug candidate with `:app:assembleDebug -PdaymarkApplicationId=io.github.sami_gor.daymark.v25ttsvalidate`.
2. Install only the isolated candidate; no production package is touched.
3. In airplane mode, open Hear today in English, French and Spanish; verify first audio, full narration, stop/restart, repeated runs and background/foreground transitions.
4. Capture Logcat, first-buffer timings, synthesis timings, generated audio duration, RTF and memory.
5. Obtain human listening review and record it separately from host benchmark results.
6. Run `scripts/verify-narration-package.mjs` against the release AAB.
