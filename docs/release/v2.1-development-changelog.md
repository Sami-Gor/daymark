## Phase 1 — Compound intent recognition and answer completeness

**Status:** complete (2026-11-01)

### Implemented

- Added stable intent IDs while preserving every existing ID:
  - `daymark.snow`
  - `daymark.fog`
  - `daymark.humidity`
  - `daymark.cloud`
- Added deterministic vocabulary for snow, fog/mist, humidity, and cloud/overcast
  conditions, including English, French, and Spanish terms.
- Added current-condition summaries for snow, fog, humidity, and cloud cover.
- Extended command and deep-link resolution for the added subjects.
- Compound questions retain all requested subjects rather than returning only
  the first match.
- Combined answers:
  - preserve the deterministic resolver order;
  - de-duplicate repeated intents;
  - remove repeated sentences and display clauses;
  - suppress the current-conditions “raining now” suffix when a rain intent
    already answers that fact;
  - explicitly state unavailable data without inventing values.
- Updated English, French, and Spanish copy and the unknown-intent guidance.
- Added an integrated Ask Daymark E2E path using a test-scoped Android
  Capacitor bridge; the real component, resolver, and composition are exercised.

### Phase 1 limitations

- Snow, fog, humidity, and cloud cover are answered from current conditions.
  Future-period snow/fog/cloud detail remains the responsibility of the
  existing tomorrow/hourly intents and is not expanded in Phase 1.
- Duplicate suppression removes repeated intent results, exact repeated
  sentences, repeated display clauses, and the known current-rain duplication.
  It is not a semantic paraphrase engine.
- The Ask Daymark E2E test supplies a test-scoped Android bridge; it does not
  replace physical-device voice testing, which remains in Phase 4.
- No multilingual narration, benchmark, lifecycle, location, or privacy phase
  work was started.

3. **Phase 2 — D:** replacement 200-utterance integrated speech-accuracy benchmark; protocol is prepared and awaiting owner approval.
